# Box Office Revenue Analysis

## Problem

This project analysed film production and release data to explore patterns associated with box office revenue performance.

## Objective

- Examine relationships between production features and box office revenue
- Explore how budget and release characteristics related to financial outcomes
- Identify observable trends across films using descriptive statistics and visualisation
- Prepare variables for structured quantitative analysis of revenue behaviour

## Key Findings

- Production budget showed observable variation alongside box office revenue across comparative plots
- Release characteristics displayed differences in revenue performance across categories
- Correlation analysis identified measurable linear relationships between selected numerical variables
- Revenue distributions exhibited skewed behaviour typical of film earnings datasets
