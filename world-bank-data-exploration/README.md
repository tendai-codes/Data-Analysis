# World Bank Data Exploration

## Problem

This project analysed World Bank development indicator data to explore global socio-economic patterns across countries using statistical summaries and visualisation.

## Objective

- Examine distributions of selected development indicators across countries
- Compare indicator behaviour between regions and income groups
- Identify observable variation across socio-economic measures
- Support structured interpretation of global development trends using quantitative data

## Approach

- Imported World Bank indicator datasets for multiple countries
- Cleaned and structured variables for comparative analysis
- Generated descriptive statistics for selected indicators
- Created visualisations to examine cross-country and regional patterns

## Key Findings

- Development indicators showed measurable variation across countries and regions
- Comparative visualisations highlighted differences between income group classifications
- Indicator distributions revealed observable disparities across socio-economic measures
- Structured summaries supported cross-country comparison of development outcomes
