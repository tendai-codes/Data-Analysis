# Portfolio Asset Allocation and Statistical Data Analysis

## Problem

This project analysed historical asset return data to examine portfolio allocation behaviour and evaluate risk and return characteristics across multiple financial assets.

## Objective

- Analyse return behaviour across selected financial assets
- Measure portfolio risk and performance using statistical metrics
- Examine relationships between assets using correlation analysis
- Support portfolio allocation decisions using quantitative comparisons

## Approach

- Retrieved historical price data for multiple portfolio assets
- Computed return series from asset price movements
- Calculated statistical measures including variance, covariance, and correlation
- Analysed portfolio-level risk and return characteristics using aggregated metrics

## Key Findings

- Asset return series showed variation in volatility across the selected portfolio components
- Correlation analysis identified differing levels of co-movement between assets
- Portfolio-level risk measures reflected the combined variability of constituent assets
- Comparative statistical metrics supported evaluation of diversification behaviour within the portfolio
