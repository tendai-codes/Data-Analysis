# Financial Statement Analysis

## Problem

This project analysed company financial statement data to examine performance trends and assess financial position using key accounting metrics.

## Objective

- Examine financial statement components across reporting periods
- Calculate financial ratios to evaluate profitability, liquidity, and leverage
- Compare performance indicators across time using structured metrics
- Support interpretation of company financial condition through ratio analysis

## Approach

- Imported financial statement data from structured sources
- Computed key financial ratios from income statement and balance sheet variables
- Analysed trends across financial indicators over time
- Visualised metric behaviour to support comparative interpretation

## Key Findings

- Profitability ratios showed variation across reporting periods based on computed results
- Liquidity measures reflected changes in short-term financial capacity over time
- Leverage ratios indicated observable differences in capital structure across periods
- Ratio-based comparisons provided structured insight into overall financial performance trends
