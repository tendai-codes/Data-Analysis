# Stocks Data Analysis and Visualization

## Problem

This project analysed historical stock market data to examine price behaviour and identify observable trends across selected equities using statistical analysis and visualisation.

## Objective

- Examine historical stock price movements across selected companies
- Analyse return behaviour using computed daily percentage changes
- Compare performance patterns between multiple equities
- Support interpretation of market behaviour using visual exploration

## Approach

- Retrieved historical stock price data for selected equities
- Calculated daily returns from closing price series
- Generated time-series visualisations to examine price trends
- Compared return distributions across multiple stocks

## Key Findings

- Stock price series showed observable variation in movement across the analysis period
- Daily return calculations highlighted differences in volatility between equities
- Time-series plots revealed distinct trend behaviour across selected stocks
- Comparative distribution analysis showed variation in return dispersion between assets
