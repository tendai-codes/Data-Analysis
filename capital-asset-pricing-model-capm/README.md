# Capital Asset Pricing Model (CAPM) Analysis

## Problem

This project analysed stock return behaviour relative to market performance to estimate systematic risk and evaluate expected returns using the Capital Asset Pricing Model (CAPM).

## Objective

- Examine the relationship between individual stock returns and market returns
- Estimate the beta coefficient as a measure of systematic risk
- Apply the CAPM formula to calculate expected stock returns
- Compare observed returns with model-based expectations

## Approach

- Retrieved historical stock and market index price data
- Computed daily returns from price series
- Estimated beta using regression between stock and market returns
- Applied the CAPM equation to calculate expected return values

## Key Findings

- Regression analysis produced a beta estimate describing the stock’s sensitivity to market movements
- Market and stock return comparisons showed observable co-movement over the analysis period
- The CAPM equation generated expected return estimates based on systematic risk
- Differences between expected and observed returns were examined within the CAPM framework
